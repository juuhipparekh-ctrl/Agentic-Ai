GitHub is ==a cloud-based website and tool that lets people store, share, and work together on code==. It is built on top of **Git**, a system that tracks changes to files

- **Repositories:** Folders or storage spaces on the cloud where project files and code live.

- **Version Control:** Keeps a clear history of every change made, making it easy to undo mistakes.

- **Collaboration:** Allows multiple people to work on the same project at the same time without breaking each other's work.
